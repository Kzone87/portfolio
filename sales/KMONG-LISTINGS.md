# 범위 방어

- 시작가는 범위가 고정된 1차 버전 기준입니다.
- 가격을 낮출 때는 기능 범위도 함께 줄입니다.
- 신규 화면/도메인/provider/연동은 기본 수정이 아니라 신규 기능으로 산정합니다.
- 서버·도메인·문자·메일·결제·AI provider·OCR·vector DB 등 외부 비용은 별도입니다.
- 공개 Demo에는 실제 API Key, 고객 데이터, 비공개 사업 코드를 사용하지 않습니다.
