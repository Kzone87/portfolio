# 유지보수 / 운영지원 판매 기준

개발 프로젝트 납품 이후 또는 기존 시스템 인수 이후의 운영지원을 **월 포함시간과 대응 기준이 명확한 Retainer**로 제공합니다.

## 월 플랜

| 플랜 | 월 비용 | 포함시간 | 대응 시작 기준 | 적합한 상황 |
| --- | ---: | ---: | --- | --- |
| CARE | 15만원 | 월 1시간 | 영업일 2일 이내 | 변경이 거의 없는 시스템 |
| OPS | 30만원 | 월 3시간 | 영업일 1일 이내 | 꾸준히 사용하는 업무시스템 |
| PRIORITY | 50만원 | 월 5시간 | 영업일 기준 당일 | 요청 빈도가 높고 빠른 초기 확인이 필요한 시스템 |

> 대응 시작 기준은 해결 완료시간을 보장하는 SLA가 아닙니다. 문제 재현, 로그 확인, 영향 범위 파악 등 기술 대응을 시작하는 기준입니다.

---

# 포함 가능한 작업

- 납품 범위 내 버그 재현/원인 확인
- 작은 코드 수정
- validation / 설정 / 문구 변경
- 작은 UI/API 보정
- 간단한 데이터 처리 수정
- 외부 API 경미한 호환성 변경 대응
- 월 작업 내역 정리
- 다음 개선 우선순위 상담

# 별도 견적 작업

다음은 기본 Retainer의 유지보수로 간주하지 않습니다.

- 신규 화면 또는 신규 업무 도메인
- 새로운 DB 관계/대규모 schema 변경
- 신규 결제/문자/메일/외부 API 연동
- 대규모 데이터 migration
- Queue/Worker/실시간 처리 신설
- 복잡한 권한/승인 단계 추가
- 전체 UI redesign
- 새로운 모바일 앱
- 시스템 전체 재개발

월 포함시간 안에서 끝나는 작은 개선은 PRIORITY 플랜에서 협의할 수 있지만, **새로운 완료 조건이 생기는 기능은 원칙적으로 신규 개발 범위**로 봅니다.

---

# 시간 계산 원칙

포함시간에는 실제 개발 작업뿐 아니라 아래 기술 작업이 포함될 수 있습니다.

- 문제 재현
- 로그/DB/코드 확인
- 수정
- 테스트
- 배포 준비
- 변경사항 문서화

단순 메시지 확인이나 계약/일정 조율은 개발시간으로 과도하게 계산하지 않습니다.

월 포함시간은 다음 달로 이월되지 않습니다.

초과 작업이 예상되면 임의로 진행하지 않고 먼저 추가 범위와 비용을 안내합니다.

---

# 외부 코드베이스 Onboarding

다른 개발사 또는 내부 개발자가 만든 시스템은 유지보수 계약 전에 상태 확인이 필요합니다.

확인 항목:

- 저장소 접근 가능 여부
- 로컬 실행 가능 여부
- 빌드 성공 여부
- DB schema
- 환경변수/secret 구조
- 배포 방법
- 테스트 유무
- 최근 장애/오류
- 외부 API 목록

분석 결과에 따라:

1. 바로 월 유지보수 가능
2. 선행 안정화 작업 후 유지보수 가능
3. 현재 구조에서는 유지보수 계약이 어려움

중 하나로 판단합니다.

# 기본 제외

월 운영지원 기본 상품에는 다음이 포함되지 않습니다.

- 24/7 상시대기
- 휴일/야간 on-call
- 현장 상주
- 서버/DB/도메인 요금
- 문자/이메일/결제/API 사용료
- 클라우드 장애 자체에 대한 보상
- 검색순위/매출/트래픽 보장
- 외부 서비스 정책변경에 대한 무제한 대응

# 장애 대응 기준

장애를 세 단계로 나눠 소통합니다.

## Critical

핵심 업무 자체가 불가능하거나 전체 사용자가 접근하지 못하는 상태.

PRIORITY 고객은 영업일 기준 가능한 한 우선 확인합니다. 24/7 SLA는 별도 계약이 없으면 제공하지 않습니다.

## Major

주요 기능 일부가 실패하지만 우회 방법 또는 다른 기능은 사용 가능한 상태.

플랜의 대응 시작 기준에 따라 확인합니다.

## Minor

문구, 표시, 편의 기능, 일부 비핵심 동작 문제.

월 작업 큐에서 우선순위를 조정해 처리합니다.

# 유지보수 상담 시 받을 정보

1. 시스템 URL 또는 실행 환경
2. 저장소/소스 접근 가능 여부
3. 사용 기술을 아는 범위에서
4. 사용 인원
5. 최근 자주 발생하는 문제
6. 월 예상 수정 요청 횟수
7. 원하는 대응 속도
8. 외부 API/결제/메일 등 주요 연동
