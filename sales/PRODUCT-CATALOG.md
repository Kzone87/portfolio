# 실제 판매상품 마스터 카탈로그

이 문서는 크몽·숨고 등 개발 수주 플랫폼에서 판매할 상품을 **고객 검색어와 완료 결과 기준**으로 고정하는 내부 영업 기준입니다.

포트폴리오에서는 가격을 노출하지 않습니다. 가격·견적·결제·계약은 플랫폼에서 진행하며, 공개 사이트는 아래 상품을 만들 수 있다는 증거만 제공합니다.

## 상품별 완료 기준

### 1. 기존 웹사이트 기능 추가
- 기능을 사용할 사용자와 권한이 정의됨
- 입력 → 처리 → 결과가 재현됨
- 기존 기능의 핵심 회귀가 깨지지 않음
- 배포 또는 전달 가능한 변경분 제공

### 2. Excel·CSV 자동화
- 샘플 원본에서 원하는 결과가 반복 생성됨
- 오류/누락/중복 처리 기준이 정의됨
- 결과 파일 형식이 합의된 양식과 일치함

### 3. 관리자페이지
- 로그인/권한 범위가 분리됨
- 고객·업무 등 핵심 데이터의 조회/등록/수정 가능
- 상태 흐름과 승인/반려 기준이 작동함
- 필요한 목록/검색/보고서 제공

### 4. API 연동
- API 요청/응답과 저장 필드가 정의됨
- 실패 시 오류를 숨기지 않고 기록함
- 반복 요청/중복 이벤트 처리 기준이 있음
- 운영자가 재처리할 수 있는 경계가 있음

### 5. 문서 추출
- 문서별 필요한 필드가 정의됨
- 누락/형식 오류를 검수할 수 있음
- 자동 추출과 사람 확인의 경계가 있음
- 결과를 합의한 CSV/XLSX/DB 구조로 전달

### 6. AI 기능 추가
- AI 입력·출력 형식이 고정됨
- 참고자료/근거 사용 여부가 표시됨
- 자동 확정하지 말아야 할 결과는 사람 검토로 보냄
- 실제 provider 비용과 개발비를 분리함

### 7. 쇼핑몰 운영
- 주문·결제·배송 상태를 혼동하지 않게 분리
- 보류/취소/반품/환불 예외 흐름이 정의됨
- 민감한 환불은 권한을 분리할 수 있음

### 8. 예약·현장업무
- 예약 시간 충돌 기준이 정의됨
- 담당자 배정/재배정이 가능함
- 방문 전/중/완료 상태가 추적됨

### 9. 공개 웹데이터 수집
- 대상 URL과 필요한 필드가 합의됨
- 허용된 공개 데이터만 처리함
- 수집 실패/중복/형식오류를 결과에서 구분함

### 10. 기존 서비스 오류수정·유지보수
- 재현 조건과 정상 동작을 먼저 합의함
- 수정 전후 검증 방법을 남김
- 신규 기능은 결함수정과 별도 범위로 분리함

## 업셀 흐름

`작은 기능/데이터 수집 → Excel/API 자동화 → 관리자 모듈 → 독립 업무시스템 → 월 유지보수`

저가 상품은 가격경쟁 자체가 목적이 아니라 **첫 거래와 리뷰 확보 후 더 큰 업무 모듈로 연결하는 입구상품**으로 사용합니다.

## 운영 원칙

- 기술명보다 고객이 검색하는 작업명을 사용합니다.
- 가격을 낮출 때는 범위도 같이 줄입니다.
- `무제한 수정`, `모든 기능 포함` 같은 표현은 사용하지 않습니다.
- 고객 샘플 데이터와 완료 결과를 먼저 확인합니다.
- 외부 API/AI/OCR 등 사용료는 개발비와 분리합니다.
- 공개 포트폴리오에는 공개 저장소와 가상 데이터만 사용합니다.
- 비공개 사업 프로젝트는 판매 증거로 사용하지 않습니다.
