# Marketplace Sales Kit

공개 포트폴리오를 실제 외주 수주와 반복 매출로 연결하기 위한 판매 문서 모음입니다.

## 1. 크몽 상품 등록

[`KMONG-LISTINGS.md`](./KMONG-LISTINGS.md)

3개 신규 개발 상품을 분리해서 등록하는 기준:

1. 관리자페이지 / 사내 업무관리 시스템
2. Excel / CSV 반복업무 자동화
3. REST API / 외부 시스템 연동

각 상품에는 제목, 썸네일 문구, 첫 설명, 패키지 가격, 포함/제외, 상담 전 정보, 공개 증거를 정리했습니다.

## 2. 숨고 견적 응답

[`SOOMGO-QUOTES.md`](./SOOMGO-QUOTES.md)

고객 요청서에 따라 사용할 응답 템플릿:

- 관리자/업무시스템
- Excel/CSV 자동화
- API/시스템 연동
- 정보가 부족할 때 추가 질문
- 범위 초과 요청 대응
- 예산 부족 시 1차 범위 축소

## 3. 포트폴리오 이미지/영상

[`PORTFOLIO-ASSETS.md`](./PORTFOLIO-ASSETS.md)

각 대표 프로젝트별로:

- 대표 이미지 문구
- 스크린샷 순서
- 이미지별 고객 중심 캡션
- 60초 영상 흐름
- 개인정보/민감정보 체크

를 정리했습니다.

## 4. 가격/범위 방어

[`SCOPE-RULES.md`](./SCOPE-RULES.md)

견적 시 반드시 분리할 것:

- 결함수정 / 유지보수 / 신규기능
- 단계별 개발
- 완료 조건

## 현재 신규 개발 가격축

| 범위 | 시작가 |
| --- | ---: |
| 작은 기능 / 단일 자동화 | 49만원 |
| 관리자 기능 / 업무자동화 | 149만원 |
| 풀스택 업무시스템 | 299만원 |

크몽 개별 상품에서는 프로젝트 특성에 따라 상위 패키지를 더 크게 잡을 수 있습니다. 예를 들어 관리자 웹 시스템은 149 / 299 / 499만원 이상 구조로 제안할 수 있습니다.

## 운영 원칙

- 가격을 낮추면 범위도 같이 줄입니다.
- 기능 개수보다 업무 복잡도로 견적합니다.
- 구매 전 요구사항을 확인합니다.
- 완료 조건을 사용자 행동으로 씁니다.
- 유지보수는 포함시간과 대응 기준을 명시합니다.
- 신규 기능과 유지보수를 구분합니다.
- 공개 포트폴리오에는 공개 저장소와 가상 데이터만 사용합니다.
- 비공개 사업 프로젝트는 판매 증거로 사용하지 않습니다.
