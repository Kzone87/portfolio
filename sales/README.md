# Marketplace Sales Kit

## 1. 크몽 기본 상품 등록

[`KMONG-LISTINGS.md`](./KMONG-LISTINGS.md)

기본 신규 개발 상품:

1. 관리자페이지 / 사내 업무관리 시스템
2. Excel / CSV 반복업무 자동화
3. REST API / 외부 시스템 연동

각 상품에는 제목, 썸네일 문구, 첫 설명, 패키지 가격, 포함/제외, 상담 전 정보, 공개 증거를 정리했습니다.

## 운영 원칙

- 가격을 낮추면 범위도 같이 줄입니다.
- 기능 개수보다 업무 복잡도로 견적합니다.
- 구매 전 요구사항을 확인합니다.
- 완료 조건을 사용자 행동으로 씁니다.
- AI는 자동 실행 범위와 사람의 승인 지점을 먼저 정합니다.
- AI/API provider 사용료는 개발비와 분리합니다.
- 유지보수는 포함시간과 대응 기준을 명시합니다.
- 신규 기능과 유지보수를 구분합니다.
- 공개 포트폴리오에는 공개 저장소와 가상 데이터만 사용합니다.
- 비공개 사업 프로젝트는 판매 증거로 사용하지 않습니다.
