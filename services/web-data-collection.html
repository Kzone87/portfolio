PUBLIC WEB DATA COLLECTION

공개 웹페이지의 필요한 값만
자동으로 모아 Excel로 정리합니다.

사람이 여러 페이지를 열어 제목, 가격, 날짜, 상태 같은 값을 복사하는 반복작업을 수집·정리·중복제거·결과파일 생성 흐름으로 바꾸는 작업입니다. 사이트 정책과 접근권한을 확인할 수 있는 공개 데이터만 대상으로 합니다.

WHAT TO SEND

수집할 페이지와 원하는 결과 열을 알려주시면 됩니다.

대상 URL

수집할 공개 페이지 또는 목록/상세 페이지 예시.

필요한 값

예: 상품명, 가격, 날짜, 링크, 상태, 업체명.

수집 범위

몇 페이지·몇 건인지, 1회성인지 반복 실행인지.

결과 형식

CSV, XLSX 또는 기존 시스템 업로드용 컬럼 구조.

OUTPUT

수집보다 중요한 건 바로 쓸 수 있는 결과입니다.

수집

  • 허용된 공개 페이지 조회
  • 목록/상세 값 추출
  • 페이지 이동
  • 수집 실패 기록

정리

  • 빈값·형식 검사
  • 중복 제거
  • 날짜·금액 정규화
  • 원본 URL 보존

결과

  • CSV/XLSX 생성
  • 실패 목록 분리
  • 기존 양식 컬럼 맞춤
  • 반복 실행 구조
