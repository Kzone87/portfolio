FAQ

상담 전에 자주 확인하는 내용

화면 수만 알려주면 견적이 나오나요?

화면 수보다 사용자 권한, DB 관계, 상태 전이와 외부 연동이 비용에 더 큰 영향을 줍니다.

Excel로 관리하던 데이터를 옮길 수 있나요?

기존 양식과 데이터 규모를 확인한 뒤 import 또는 migration 범위를 별도로 산정할 수 있습니다.

전체 시스템이 부담되면 작게 시작할 수 있나요?

가능합니다. 핵심 CRUD와 상태 처리부터 1차 버전으로 완료하고 권한·Audit·연동을 후속 단계로 분리할 수 있습니다.

기존 프로젝트 수정도 가능한가요?

가능하지만 먼저 로컬 실행, 빌드, DB, 환경변수, 변경 대상 의존성을 확인한 뒤 범위를 정합니다.
