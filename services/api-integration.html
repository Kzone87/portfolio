FAQ

연동 견적 전에 확인하는 내용

API 문서가 꼭 필요한가요?

가능하면 필요합니다. 문서가 없다면 기존 호출 예시나 테스트 계정/개발 환경을 통해 별도 분석 범위를 먼저 잡습니다.

Webhook이 두 번 오면 어떻게 하나요?

provider의 event ID나 업무 unique key를 이용해 중복 처리를 막습니다. 공개 V3는 connectionId + eventId 조합으로 deduplication을 재현합니다.

실패한 연동은 자동 재시도하나요?

업무 특성에 따라 retry 횟수, backoff, 재시도 금지 오류를 구분합니다. 반복 실패는 운영자가 별도로 확인할 Dead Letter 흐름을 둘 수 있습니다.

API Key를 포트폴리오처럼 공개하나요?

아닙니다. 실제 프로젝트 secret은 서버 환경이나 적절한 secret 관리 경계에 두고 공개 소스에 넣지 않습니다.
