EXCEL · CSV AUTOMATION

매번 파일을 열어 정리하던 일을
버튼 몇 번으로 끝냅니다.

거래처마다 다른 Excel 양식을 맞추고, 중복과 잘못된 값을 찾고, 지난달 파일과 이번달 파일을 비교하고, 여러 파일을 같은 규칙으로 정리하는 작업을 자동화합니다. 반복되는 수작업이 명확할수록 효과가 큽니다.

WHEN IT HELPS

이런 파일 작업을 자동화할 수 있습니다.

자료 정리

공백, 전화번호, 이메일 형식, 중복 행을 매번 손으로 정리할 때.

양식 통일

업체마다 다른 컬럼명을 회사 표준 양식으로 바꿔야 할 때.

전월·당월 비교

두 파일에서 새로 생긴 항목, 삭제된 항목, 값이 바뀐 항목을 찾아야 할 때.

여러 파일 일괄 처리

같은 규칙을 수십 개 파일에 반복 적용하고 결과를 하나로 합쳐야 할 때.

Excel / CSV 불러오기 ↓ 오류·중복 검사 ↓ 정리·컬럼 변환 ↓ 필요하면 이전 파일과 비교 ↓ CSV / Excel 결과 다운로드

WHAT CAN BE INCLUDED

현재 수작업 순서에 맞춰 조합합니다.

정리·검사

  • 빈값 / 이메일 / 숫자 형식 검사
  • 공백·전화번호 형식 통일
  • 중복 제거
  • 오류 목록 리포트

변환·비교

  • 컬럼명 변경
  • 회사 표준 양식으로 변환
  • 두 파일 변경점 비교
  • 변경 전/후 값 확인

일괄 처리

  • 여러 파일 한 번에 처리
  • 작업 순서 재사용
  • 파일별 성공/오류 결과
  • 정상 결과 통합 다운로드

HOW IT WAS BUILT

Customer Data Workbench · V3

위 과정을 브라우저에서 직접 실행할 수 있는 공개 도구입니다. TypeScript/Vite/SheetJS로 구현했으며 Rule Builder, Column Mapping, Dataset Compare, Batch/Migration, CSV/XLSX Export와 자동 테스트를 포함합니다. 파일은 브라우저 안에서 처리하는 local-first 구조입니다.
