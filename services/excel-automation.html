FAQ

상담 전에 자주 확인하는 내용

API Key나 서버가 꼭 필요한가요?

단순 파일 검증·정리·변환은 필요하지 않습니다. 브라우저 local-first 방식으로 구성할 수 있습니다.

파일이 서버에 올라가나요?

local-first 범위라면 업로드하지 않습니다. DB 저장·공유·로그인이 필요한 경우에만 서버 구조를 별도로 설계합니다.

샘플 파일을 보내야 하나요?

가능하면 필요합니다. 실제 컬럼과 예외 데이터를 알아야 정확한 규칙과 견적을 잡을 수 있으며 개인정보는 제거해도 됩니다.

10만 행 같은 대용량도 가능한가요?

처리량에 따라 브라우저 메모리 방식보다 서버/Worker/스트리밍 구조가 적합할 수 있어 데이터 규모를 먼저 확인합니다.
