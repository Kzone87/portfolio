PR #49는 2024년 팀 개발 당시 기능 기여와 별개의 2026년 유지보수 작업입니다. 포트폴리오에서는 두 시점을 합쳐 과장하지 않고 각각의 목적을 분리합니다.

제가 다룬 서비스 흐름

SEARCH

외부 API + 내부 DB

Naver Book Search 결과와 내부 도서 DB 검색을 별도 경로로 연결하고 JSON으로 브라우저에 전달했습니다.

AUTH

비밀번호와 소셜 로그인

당시 사용자별 salt 기반 hash 검증과 Naver 사용자 등록/로그인 흐름을 구현했습니다.

STATE

장바구니 / 위시리스트

레코드 조회→대상 삽입→원본 삭제로 이어지는 상태 이동을 구현했습니다.

ORDER

마이페이지 / 주문취소

구매 식별자, 수량, 가격과 취소 데이터를 연결하고 회원 상태 변화까지 다뤘습니다.

ADMIN

관리자 라우팅

관리자 로그인과 `/admin/*` 요청을 JSP 화면에 연결하는 Servlet routing을 보완했습니다.

MIGRATION

Jakarta 전환

프로젝트 후반 Tomcat 10 실행환경에 맞춰 `javax.servlet`에서 `jakarta.servlet`로의 전환에 참여했습니다.

당시 구조

BrowserJSP · JavaScript

MySQLmember · book · order

현재 다시 만든다면

Layered architecture

JSP와 JDBC에 섞인 책임을 Controller–Service–Repository와 DTO 경계로 분리합니다.

Transactional state changes

장바구니→위시리스트, 구매→취소 같은 다중 SQL을 하나의 transaction으로 묶습니다.

Modern authentication

직접 SHA-256을 조합하지 않고 Argon2id/bcrypt와 검증된 security framework를 사용합니다.

2026 보안 유지보수

과거 학습 프로젝트에 남아 있던 hardcoded API/DB credential, OAuth token 출력, debug profile 정보와 tracked build/ZIP을 현재 main에서 제거했습니다. OAuth state 검증과 환경변수 기반 설정도 추가했습니다.

Credential boundary

현재 코드는 실제 credential 없이 환경변수 이름과 연결 구조만 유지합니다.

Token exposure

callback과 후처리에서 token/사용자 프로필을 로그·화면에 출력하던 경로를 제거했습니다.

History decision

폐기한 credential의 과거 Git 이력은 협업 증거 보존을 위해 rewrite하지 않았습니다.
