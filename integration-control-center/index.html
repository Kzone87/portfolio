V2 DESIGN PRINCIPLES

UI와 서버 경계를 함께 보여줍니다.

  • Credential separation실제 API Key를 프런트 코드나 데모 데이터에 넣지 않습니다.
  • Explicit stateConnection, Job, Run 상태를 구분합니다.
  • Failure contract서버에서 validation과 400/404/409 오류를 명시적으로 처리합니다.
  • Idempotency동일 실행 요청의 중복 기록을 Idempotency-Key로 방지합니다.
  • Auditability성공·실패 결과와 처리 건수를 Run history로 남깁니다.
