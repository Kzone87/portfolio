여러 사업장

지점마다 장비 고장 요청이 따로 들어옵니다.

각 지점이 전화·메신저·개인 연락으로 요청하면 본사에서는 누가 처리 중인지, 같은 장비가 반복해서 문제를 일으키는지 파악하기 어렵습니다.

장비는 복구되지만 이전 증상, 교체 부품, 사용환경 정보가 다음 방문에 이어지지 않으면 매번 처음부터 확인하게 됩니다.

설치·이전

사무실 이전 당일에 전원·네트워크 문제로 설치가 지연됩니다.

장비 반입 일정만 정하고 전원, 네트워크, 이동 동선과 장비별 정상가동 확인 항목이 분산돼 있으면 설치 당일 재작업이 늘어납니다.

현재 불편반입·연결·가동 확인 정보가 여러 담당자에게 분산

사무환경

장비 담당자가 바뀔 때마다 같은 설명과 확인을 다시 합니다.

복합기와 프린터 설정, 이전 장애 이력을 특정 담당자만 알고 있으면 인수인계 때마다 장비 상태를 새로 파악해야 합니다.
